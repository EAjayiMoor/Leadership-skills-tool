# UI standard adoption note

The [Moorhouse UI Standard](Moorhouse-UI-Standard.md) is an unchanged copy of the file supplied for this project (version 1.0, dated 24 April 2026; SHA-256 `ce2097d9c88d50d8f08636296adb8200c9266b09348bb4b15932c2ed098f4492`). Keep the source intact. Record product-specific decisions and exceptions in the [decision log](../decision-log.md), rather than editing the source standard silently.

Apply its principles, palette, typography, spacing, components, motion and accessibility to the web interface design. Its code references describe the Summit implementation and a proposed shared package; this repository does not contain the logo, Summit components or `@moorhouse/ui`, and the web framework is still open. Check actual contrast, keyboard operation and responsive behaviour in this product. The standard sets WCAG 2.1 AA as a floor; the product design and test files target WCAG 2.2 AA.

Open items from the source include the full tone-of-voice guide, component definitions listed in §8.9, shared package, illustration system and motion library. Their absence is a design input to resolve as needed, not a reason to invent assets or claim those components already exist.
