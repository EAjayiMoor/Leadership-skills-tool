# 6 Maintain

## Purpose

Keep the product reliable and learn whether it is improving assessment work.

## Operating loop

- Monitor availability, latency, failed imports/exports, access issues and incident reports against named alert owners and response targets.
- Triage defects, security issues and data incidents by impact; document response, escalation, user communication, recovery and post-incident learning. Keep a route to rollback or suspend use.
- Collect consultant feedback after each assessment and compare setup time, preparation time, rework and report corrections with the Plan baseline.
- Review finding quality, provenance, heatmap interpretation and approved report use with assessment owners; correct or withdraw outputs when source evidence changes.
- If AI features are live, sample outputs against the approved evaluation set, watch for unsupported claims and changing behaviour, and review provider/model/prompt changes before rollout.
- Review access grants, audit records, retention/deletion completion, backup/restore tests and client separation on an agreed schedule.
- Review dependencies, vulnerabilities, framework updates, skill versions and the UI standard before upgrades; test migrations and accessibility regressions.
- Use evidence from a second and later assessment to decide whether to standardise, extend or retire features. Feed new needs back through Plan and Design, with an owner and measure.

## Operational records

Maintain a service owner/contact list, incident log, known-issues list, support feedback, outcome dashboard, risk register, change history and review calendar. Set frequencies and thresholds once the hosting model and pilot audience are chosen.

## Exit evidence for each improvement cycle

An updated outcome measure, prioritised change, test result, release record when deployed and decision record. Promote a feature only when it solves an observed problem in the target workflow and preserves the data and method controls.

## AI use

AI may group feedback, diagnose faults and propose improvements from permitted operational data. Humans review any change affecting assessment conclusions, permissions, AI processing or live data handling.
