# 6 Maintain

## Purpose

Keep the product reliable and learn whether it is improving assessment work.

## Operating loop

- Monitor availability, failed imports, export failures, access issues and incident reports.
- Collect consultant feedback after each assessment and record time/rework measures.
- Review quality of findings, provenance and heatmap interpretation with assessment owners.
- Triage defects and security issues by impact; keep a clear route to rollback or suspend use.
- Review dependencies, skill versions and framework updates before upgrades.
- Review retention and deletion obligations on schedule.
- Use evidence from a second and later assessment to decide whether to standardise, extend or retire features.

## Exit evidence for each improvement cycle

An updated outcome measure, prioritised change, test result and decision record. Promote a feature only when it solves an observed problem in the target workflow.

## AI use

AI may group feedback, diagnose faults and propose improvements. Humans review any change affecting assessment conclusions, permissions or live data handling.
