# 3 Build

## Purpose

Implement the agreed design in small vertical slices that can be demonstrated and checked.

## Working sequence

1. Set up the chosen application stack, repository checks and a safe sample-data environment.
2. Implement engagement configuration and question variation.
3. Implement import validation and evidence organisation.
4. Implement interview briefing preparation and editing.
5. Implement evidence-linked cohort findings and review states.
6. Implement the agreed heatmap and report export.

Each slice needs a user-facing outcome, acceptance examples, relevant automated checks and a short demo. Maintain a link from requirement to implementation and test evidence. Review AI-generated code for correctness, security, dependencies and data handling.

## Exit evidence

- The agreed first slice works end to end with approved prototype data.
- A second configuration can be created without code changes.
- Findings retain provenance and review state through export.
- No secrets or live client evidence are committed to the repository.

## AI use

Use Expo skills if Expo is the chosen stack. Use Superpowers planning, debugging and verification methods where they fit the task. Skills guide implementation; the reviewed design remains authoritative.
